## Диагностика

Скрипт scripts/diskcheck.sh выводит дату, аптайм, свободное место на диске, использование памяти и топ-5 процессов по памяти.

## Планы

- Добавить эндпоинт /health для проверки состояния приложения

## Автодеплой (не реализовано)

Чтобы приложение деплоилось на ВМ автоматически, в CI можно добавить:
1. После успешных тестов — сборку Docker-образа с тегом версии.
2. Публикацию образа в Yandex Container Registry (docker push), используя логин и токен, сохранённые в GitHub Secrets.
3. Подключение к ВМ по SSH из пайплайна, используя приватный ключ, тоже хранящийся в Secrets, а не в самом ci.yml.
4. На ВМ — docker compose pull, чтобы скачать новый образ, и docker compose up -d, чтобы перезапустить контейнер с обновлённой версией.
5. Проверку через curl /health после деплоя, чтобы убедиться, что новая версия действительно поднялась.
